This contract records the existing shared runtime grammar for future source-first readers. It provides source-blank examples only. It is not a classification guide, key proposal, pixel interpretation or permission to expose a future card. Freeze source observations, raw coding, independent comparison and exact review decisions before literal projection. Do not change a frozen source to satisfy software; report unsupported schemas for a reviewed read-only adapter.

A source manifest must enumerate both original faces and every observed cipher region, including margins and edges. Use explicit geometric display order selected before literal values. If two regions have different orientations, save separate cipher documents and bind their order and frames; do not stitch them by linguistic fit. Address presence or absence must come from a complete source survey, never be assumed from the picture face. Source ordinary handwriting, printed text and nontext marks are separate direct observations.

Each canonical cipher document is a JSON object with `card` (integer), `source` (exact saved `sha256`, `dimensions:[width,height]`, `bytes`, `source_url`), `orientation`, `oriented_dimensions`, `physical_body_count:null`, and a nonempty `rows` list. Do not add top-level `schema` or `schema_version` to a canonical cipher document; a sidecar manifest may name a schema. Supported coordinate frames are `NONE`, `CCW90`, `CW90` and `ROTATE_180`. These declare the exact full-source coordinate transform. If native coordinates are retained while glyphs are viewed quarter-turned, use `orientation:"NONE"` and separate `coordinate_frame`, `glyph_read_orientation` and `reading_direction` metadata. Never rotate coordinates solely to fit a graphical reading pose.

Rows have unique nonempty `id`, required `bbox_xyxy`, and a nonempty `groups` list. Groups have globally unique `id`, `bbox_xyxy`, `physical_body_count:null`, a nonempty `units` list and `punctuation:[]` if no marks are recorded. Units have globally unique `id`, `bbox_xyxy`, `class_id:null` or a class identifier from the unchanged neutral atlas, `alternatives:[]`, `status`, `shape_notes`, and `physical_body_count`. Do not include plaintext, key values, accepted literal values or guessed words in source coding. Optional `row_index`, `group_index` and `unit_index` must be actual one-based list positions; list order controls output.

All windows use integer `[left,top,right,bottom]` with `0 <= left < right <= width` and `0 <= top < bottom <= height` in the explicitly declared frame. They are source context windows unless independently justified as ink segmentation. Record a precision/ownership label, especially shared whole-group windows. Do not manufacture equal-width per-glyph partitions. An unresolved span has `class_id:null`, `status:"unresolved_span"`, `physical_body_count:null`; one representation record is not a measured glyph count. Document and group physical totals remain null when uncertain. An unresolved shape may use null physical count; any reader's one-body hypothesis is a recorded proposal, not an accepted mapping.

Use `status:"provisional_known_class"` only for a provisional source classification. Use `"unresolved_shape"` or `"unresolved_span"` when appropriate. Other runtime aliases are `known`, `classified`, `provisional`, `provisional_match`, `uncertain`, `unresolved`, and `unknown`; these do not upgrade accuracy. Every unresolved status, nonempty alternative list or null class remains masked, even if a preferred class is also present. Alternatives must retain all listed supported classes, without duplicates; either class strings or objects containing `class_id` are accepted. Candidate completeness, same-value candidates, fluent text and presumed letter counts do not resolve masks.

Punctuation is structured only when source ownership supports an exact saved boundary. Each mark has its own unique `id`, `bbox_xyxy`, `status`, `literal`, and exactly one of `before_unit_id` or `after_unit_id` referring to a unit in that same group. `status` is `recorded`, `known`, `uncertain` or `unresolved`; supported literals are `. , ; : ! ? - — / ( )`. A null literal or uncertain/unresolved status produces an explicit punctuation mask. Do not supply a known punctuation character or boundary from phrase meaning. If attachment is unproven, preserve the unlocated mark/ownership uncertainty in the source survey and review warnings; do not fabricate a unit boundary. Never convert a detached mark into a cipher body.

Source-blank punctuation example (replace placeholders only from direct source evidence):

```json
{
  "id": "MARK_ID",
  "bbox_xyxy": [0, 0, 1, 1],
  "status": "unresolved",
  "literal": null,
  "after_unit_id": "SOURCE_UNIT_ID"
}
```

The example illustrates field types, not a recommended window or assertion that ownership is known. Use `after_unit_id` only after observing that exact attachment. Keep mark observations with unknown attachment outside projected group punctuation and record the uncertainty explicitly.

Ordinary diplomatic documents contain `card`, `key_projection_performed:false`, and both entries in `faces:[...]`. Each face entry identifies `face`, exact source `sha256`, coordinate `orientation` (or `PER_RECORD` with independently declared record frames), and ordered `records`. Every record contains exact `transcription` (nonempty source string or explicit null), `uncertainty` (nonempty source note or explicit null), `bbox_xyxy` and its frame when records differ. For null transcription, preserve a nonempty `shape_note`; this is a nontext graphical observation, never invented text. Null uncertainty means no uncertainty was recorded, not certified certainty. Printed text should use `recorded_kind:"direct_printed_text"`. Copy spelling, spaces, line breaks, punctuation and source date attempts exactly; keep date alternatives in uncertainty and never normalize to ISO or repair wording. No classes, units, key values or accepted literals belong in ordinary records.

The complete face survey uses native source coordinates: `card`, `source_first_procedural:true`, `key_projection_performed:false`, and two entries in `faces`. Each entry has exact source metadata, `orientation:"NONE"`, native `oriented_dimensions`, boolean `cipher_present`, ordered `cipher_regions`, four nonempty edge-survey notes, and indexed ordinary coverage. A cipher region has `region_id`, `role`, its own orientation/dimensions, `bbox_xyxy` and all `observed_row_ids`. A sidecar row-region binding lists the same regions, roles and row IDs in exact raw document order.

Canonical ordinary coverage indices are one-based: `diplomatic_record_index:1` points to `records[0]`. Alternatively a single enclosing source block may have `diplomatic_record_indices:[1,2,...]`; every referenced record window must lie inside it, with one common frame. Every ordinary record needs exactly one source coverage reference. Distinguish printed blocks from handwriting; do not label a printed record as a second handwritten line. For a different source schema (including zero-based indices), preserve original bytes and state the index convention explicitly.

Freeze all source sidecars and class-free fragment nominations with hashes and exposure flags. Independent readers retain their original fragment IDs, partitions, source windows and all abstentions. A canonical nomination alias must preserve the original ID in a separate field. Review all nominations, including rejected windows, not merely successful ones. Exact review overlays mask only independently approved raw-known IDs and retain raw class/status/window/reason; never replace classes or choose preferred alternatives. Already unresolved records remain unresolved with zero extra accepted-body delta. Safe translation ranges need separate uniform source-only eligibility before target values; rejected parents and grouping warnings remain visible.
