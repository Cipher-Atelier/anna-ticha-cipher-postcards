## Result and scope

A source-first experiment on both original faces of card248 produces a substantial but incomplete Czech literal under the unchanged 24-entry model. It supports affectionate correspondence, thanks for a message, discussion of an invitation to a ball, and a warm closing. The detailed English interpretation below distinguishes readable wording from linguistic conjecture. The recorded literal still contains malformed words, uncertain bodies, unknown-count spans, disputed spacing and uncertain participation. It is not a complete plaintext or a historical accuracy claim.

The fixed active-body inventory contains 531 records. The primary model maps 514 and leaves 17 unknown. A further 24 mapped body records belong to five conditional activity groups. Fifteen other records are unresolved spans with unknown internal glyph counts. StrictV2 adds no values. Mapping coverage is not transcription accuracy: even mapped glyphs can have been visually misclassified, and meaningful-looking language cannot validate them.

This is transfer of an existing model, not a new cipher-family breakthrough. “First” below refers only to the exact first replay retained for this local experiment. An earlier project inspected ordinary address/date fields. A bounded predecessor title search found no full card248 reading among its returned results; this does not establish global novelty or prove no earlier plaintext exists.

This experiment used the nominated existing HCP image pair and neutral reference/model artifacts. This page contains no source images or museum research-only materials. The separate text evidence package and complete source apparatus remain outside this public candidate. The experiment made no external communication changes.

## Audit and preserved failures

An independent implementation reconstructed the source/model result before reading the coordinator's replay. It agrees on every current value, all 16 primary and strict row streams, eligible package values and counts, source gaps and punctuation, statistics and inverse units. Source/model manifests and row/action coverage pass. All 615 Reader B token crops reproduce from the originals under the recorded crop/rotation/3x-resizing recipes. That pixel test proves derivative provenance, not that every crop was manually inspected or every glyph correctly identified.

The first replay implementation had two latent strictV2 failures on synthetic test inputs:
1. A contradictory explicit mark token_id did not veto otherwise matching ownership_options.
2. An explicit mark-level base claim with no mark-level base confidence inherited high confidence from the containing record.

Neither defective pattern is present in actual card248 source records. Both defects are preserved in the original code and audit results. A separate V2 implementation requires consistent explicit owner claims and high confidence on each explicitly claimed base. The hardened version changes no source, key, rule, decoded value, branch, count, row or literal byte. The original literal is retained exactly, not replaced by the corrected implementation's output.

The independent audit's initial harness also contained mistakes: two Counter comparisons treated dictionary values as counts, and crop checks initially overlooked recorded 3x scaling. These produced 1,232 false failures. The initial script and results are retained; audit-only corrections changed no reconstructed values. A coordinator comparison initially attempted broad JSON equality including newly added guard diagnostics; the documented corrected comparison verifies the actual outputs and preserves the intended diagnostic/version differences.

The final technical suites report 4,932 passing integrity/graph checks, 6,954 passing hardened comparison checks including 244 guard fixtures, and 80 passing extended checks. These overlapping implementation checks are not thousands of independent confirmations of decryption accuracy. The useful findings are exact reproduction of the frozen result, preservation of uncertainty, explicit disclosure of the original defects, and absence of failures in the implemented corrected tests.

## Conclusion and next priority

The unchanged model transfers enough to yield recognizable Czech content, but source uncertainty and malformed mapped words prevent a defensible complete reading. This bounded experiment stops at the audited partial result. Its next priority should be better independent image evidence or qualified human source review if the goal is to improve card248. Re-reading the same pixels after seeing plausible Czech must not overwrite this source freeze.
